# Жасыл Ұрпақ: руководство пользователя

**Жасыл Ұрпақ** — веб-платформа для координации экоамбассадоров ТОО «Global Green Hub». Компания размещает экологические инициативы и задания, экоамбассадоры выбирают их и выполняют, а координатор проверяет отчёты и следит за ходом работы.

**Сайт:** https://nariman-bit.github.io/Test_Zhasli_Urpak/

Интерфейс доступен на русском и казахском языках. Переключатель («Қазақша» / «Русский») находится на экране входа и в правом верхнем углу.

---

## 1. Как войти

Для быстрой проверки на экране входа есть кнопки **демо-входа**:

| Кнопка | Роль | Почта | Пароль |
|---|---|---|---|
| Координатор | Координатор | coord@ggh.kz | 123 |
| Данияр | Экоамбассадор | dan@mail.kz | 123 |
| Мадина | Экоамбассадор | madina@mail.kz | 123 |

Можно также зарегистрироваться самостоятельно: вкладка **Регистрация** → имя, почта, пароль и роль.

Чтобы увидеть весь процесс, откройте платформу за координатора, а затем за экоамбассадора (кнопка **Выйти** в разделе «Профиль»).

## 3. Разделы платформы

**Сводка.** Общие показатели: число экоамбассадоров, инициатив, заданий и выполненных заданий. Ниже — ход каждой инициативы с полосой прогресса. Нажмите на инициативу, чтобы открыть подробности. У координатора вверху показано, сколько отчётов ждёт проверки.

**Инициативы.** Каталог: название, цель, сроки, ответственный координатор, статус и прогресс. Внутри инициативы видны её описание, число участников и список заданий с отчётами.

**Задания** (у экоамбассадора — **Мои задания**). Список заданий с фильтрами. У экоамбассадора: «Мои», «Свободные», «Выполненные». У координатора: «Все», «На проверке», «Свободные».

**Профиль.** Личные данные, которые можно изменить (имя, город, «о себе»). Здесь же кнопка выхода.

## 4. Как это работает: сценарий по шагам

Основной путь: **инициатива → задание → назначение → выполнение → отчёт → проверка → сводный результат**.

### Координатор
1. Откройте **Инициативы** → **Новая инициатива**. Укажите название, цель, описание, сроки, ответственного координатора и статус.
2. Откройте созданную инициативу → **Добавить задание**. Опишите задание, ожидаемый результат и срок. Исполнителя можно выбрать сразу или оставить задание свободным.
3. Чтобы назначить или сменить исполнителя позже, нажмите **Назначить** (или **Сменить**) у задания.
4. Когда экоамбассадор сдаст отчёт, задание получит статус «На проверке». Откройте его и нажмите:
   - **Принять** — задание станет «Выполнено»;
   - **Вернуть** — задание вернётся на доработку. Комментарий в этом случае обязателен.
5. Результат сразу появится в сводке и в прогрессе инициативы.

### Экоамбассадор
1. Откройте **Мои задания** → фильтр **Свободные**. Выберите задание и нажмите **Взять задание**. Оно перейдёт в «Мои» со статусом «В работе».
2. Выполните задание в реальной жизни, затем нажмите **Сдать отчёт**. Опишите, что сделано, при желании приложите файл, и нажмите **Отправить на проверку**.
3. Дождитесь решения координатора. Если отчёт вернули, задание получит статус «На доработке» и комментарий координатора. Исправьте работу и сдайте отчёт заново.
4. Принятое задание получает статус «Выполнено» и учитывается в сводке.

---

## 5. Статусы

**Задание:**
- **Свободно** — исполнитель не назначен;
- **В работе** — исполнитель назначен или взял задание;
- **На проверке** — отчёт сдан и ждёт решения координатора;
- **На доработке** — отчёт возвращён с комментарием;
- **Выполнено** — отчёт принят.

**Инициатива:** Планируется, Идёт, Завершена. Статус инициативы задаёт координатор вручную. Прогресс считается автоматически как доля выполненных заданий.

**Отчёт:** ожидает проверки, принят, возвращён.

## 6. Ограничения прототипа

Это работающий прототип для демонстрации, а не готовая промышленная система.

- **Данные хранятся в браузере** (localStorage). Каждый посетитель видит свои данные, а созданное одним пользователем не видно другим. Если открыть сайт в другом браузере или на другом устройстве, будут демонстрационные данные.
- **Сброс данных:** ссылка «Сбросить демо-данные» внизу страницы возвращает исходное состояние.
- **Файлы к отчётам:** сохраняется только название файла, сам файл на сервер не загружается.
- **Пароли** хранятся без шифрования, поэтому не используйте реальные пароли.
- **Роль** при регистрации выбирается самостоятельно. В рабочей версии координаторов должен назначать администратор.
- **Тексты, введённые пользователями** и демо-данные остаются на том языке, на котором написаны, даже при переключении интерфейса.
